The remaining screens

Every screen in src/ui/screens that the theme work had not reached yet, plus the two cards that leave the app. Built on the settled tokens: dusk accent rendered as if the user had picked it, amber reserved for the app asking you something, verdict colours fixed, the serif only ever on a human's own words.

Rules these screens are carrying

  • A hit rate is never shown for an unranked author. Both the Author screen and the Scorecard lead with the record instead.
  • Retroactive entries are marked at intake, because they never count toward a rate.
  • Criteria freeze on the first check; Review says so before you commit.
  • The API key is never in the database, and the Settings hint names the key actually in force rather than the one last typed.
  • Evidence rows show the host next to the publisher. The publisher is a name the model typed; the host is where the fetch landed.

Two changes to what is on main

  • The receipt stamp is no longer rotated or outlined. That was the case-file aesthetic this project dropped, and at feed size a tilted outline reads as a novelty sticker rather than a verdict. It is flat and filled now.
  • Both cards carry a brand rule in the icon's ramp. Fixed, never the user's accent: this is the only surface strangers ever see, so it should not change colour depending on a setting inside the app.
